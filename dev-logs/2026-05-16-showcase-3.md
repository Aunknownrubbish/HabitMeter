# Showcase-3 Deployment Readiness

Date: 2026-05-16

## Scope

Prepare deployment documentation for HabitMeter and make small configuration improvements for Vercel readiness. No product feature logic or database schema changes were made.

## Official References Checked

- Vercel Next.js documentation
- Vercel environment variables documentation
- Auth.js deployment documentation
- Auth.js core configuration documentation
- Prisma deploy-to-Vercel documentation

## Findings

- Vercel is the preferred deployment platform for this project because HabitMeter is a Next.js App Router application with API Routes.
- Streamlit is not suitable because the current project is not a Python Streamlit app.
- Current SQLite setup is appropriate for local development but should not be described as a production-ready Vercel persistence layer.
- Candidate comparison remains safe for a deployed demo because it uses browser localStorage.
- Auth.js host handling is already covered by `trustHost: true` in `src/lib/auth.ts`.
- Prisma recommends regenerating Prisma Client during Vercel builds to avoid stale generated clients.

## Changes Made

- Added `docs/deployment-guide.md`.
- Added `postinstall: prisma generate` to `package.json`.
- Updated `README.md` to link the deployment guide and clarify deployment readiness.

## Verification

- `npm run build` passed with Next.js 16.2.6.
- No database schema change was made.
- No new dependency was added.
- Deployment documentation explicitly marks SQLite login/saved-location persistence as non-production for Vercel.
