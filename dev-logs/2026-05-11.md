## 遇到的问题与解决记录

1. **Node.js 不在 PATH**
   - 工具安装在 `E:\Develop_Apps\NodeJS\`，需手动指定路径
   - 解决：所有命令使用完整路径 `E:\Develop_Apps\NodeJS\npm.cmd`

2. **create-next-app 不允许大写项目名**
   - HabitMeter 含大写字母，npm 拒绝
   - 解决：手动创建 package.json 后逐步安装依赖

3. **npm 缓存被锁定**
   - `E:\Develop_Apps\node_cache` 权限被拒
   - 解决：`npm config set cache "C:\Users\X T\.npm-cache"`

4. **next.config.ts eslint 配置已废弃**
   - Next.js 16 不支持 `eslint.ignoreDuringBuilds`
   - 解决：移除 eslint 配置项

5. **AMap JS API Loader 导致 SSR 500 错误**
   - `@amap/amap-jsapi-loader` 在 import 时引用 `window`，服务端渲染报错
   - 解决：将 `import AMapLoader from "..."` 改为 `await import("...")` 动态导入，确保只在客户端调用时加载

6. **Prisma 7 不支持原生 SQLite 连接**
   - Prisma 7.8.0 要求使用适配器（adapter）连接数据库，默认不再支持直接的 `datasourceUrl`
   - `new PrismaClient({ datasourceUrl: "file:./dev.db" })` 报 `Unknown property datasourceUrl`
   - 解决：降级到 Prisma 5.22.0，原生支持 `url = env("DATABASE_URL")` 配置

7. **Prisma 7 不兼容原生 SQLite**
   - Prisma 7.8.0 要求使用适配器，`new PrismaClient({ datasourceUrl: "..." })` 报错
   - 解决：降级到 Prisma 5.22.0，原生支持 `url = env("DATABASE_URL")`

8. **高德 JS API 2.0 安全密钥未配置**
   - AMap JS API 2.0 要求在加载脚本前设置 `window._AMapSecurityConfig = { securityJsCode: '...' }`
   - `@amap/amap-jsapi-loader` 不会自动处理安全密钥，需手动设置
   - 解决：在 `loadAMap()` 中，import 前先设置 `window._AMapSecurityConfig`
