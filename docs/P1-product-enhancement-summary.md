# P1 居住决策增强 — 产品功能总结

## 概述

P1 阶段在 MVP 基础上增强了**决策辅助能力**：从"展示数据"升级为"帮助判断"。

---

## P1-1: 居住评分模型 v1 (commit 834ea23)

**新增文件：** `src/lib/living-score.ts`

**核心能力：** 将 POI 数量和通勤结果转化为 0-100 综合评分。

**评分维度：** 通勤 35 / 交通 25 / 生活 15 / 医疗 15 / 休闲 10

**等级：** ≥85 excellent / ≥70 good / ≥50 average / <50 weak

**自动生成：** 2-4 条优势 + 1-3 条短板，基于数据自动判断。

---

## P1-2: 结论摘要卡 (commit dfdf2c2)

**新增文件：** `src/components/insights/LivingSummaryCard.tsx`

**展示内容：** 总分 + 等级徽章 + 5 维分数条 + 优势/短板列表

**空状态：** 无地址引导输入；有 A 无 B 提示补充。

**接入位置：** Sidebar（搜索后）+ MobileDrawer（"结论" tab）。

---

## P1-3: POI 可达性评价 (commit 199a699)

**新增文件：** `src/lib/poi-analysis.ts` + `src/components/poi/POISummaryPanel.tsx`

**能力：** 每类 POI 显示数量、最近距离、评价标签。

**评价规则：**

| 类别 | good | average | weak | none |
|---|---|---|---|---|
| 便利店 | ≥10 且 ≤500m | 有数据 | — | 无 |
| 地铁 | ≤1000m | ≤2000m | 有数据 | 无 |
| 公交 | ≤500m 且 ≥5 | 有数据 | — | 无 |
| 医院 | ≤1500m | 有数据 | — | 无 |
| 公园 | ≤1500m | 有数据 | — | 无 |

**效果：** 桌面/移动端共享 POISummaryPanel，消除重复代码。

---

## P1-4: 通勤推荐 (commit bf0324a)

**新增文件：** `src/lib/commute-recommendation.ts`

**推荐优先级：**
1. 公交 ≤75min → 推荐公交
2. 驾车比公交快 ≥20min → 推荐驾车（提醒路况风险）
3. 骑行 ≤45min → 可考虑骑行
4. 步行 ≤30min → 可步行
5. 兜底 → 耗时最短的（提醒通勤压力）

**CommutePanel 变化：** 推荐横幅（蓝色 + Star + reason + 警告列表），推荐方式默认展开。

---

## P1-5: 信息架构调整 (commit 4e0e355)

**Sidebar 新顺序：** 搜索 → 结论 → 通勤 → 配套 → 账号 → 收藏

**MobileDrawer 新 Tab：** 搜索 → 结论 → 通勤 → 配套 → 收藏

**初始引导：** "输入一个候选居住地，查看 3km 生活圈和通勤压力。"

**移动端顶部：** 有评分时显示 "推荐 78分 · 24个周边设施"
