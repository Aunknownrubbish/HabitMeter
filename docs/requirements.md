# 产品需求文档 — HabitMeter（寻栖）

## 1. 产品定位

**寻栖** 是一款全国通用的居住环境决策工具。帮助租房/购房者在做决定前，直观评估意向居住地周边的配套设施和生活便利度，同时量化通勤成本。

**目标用户**：正在寻找住所、需要比较多个意向地址通勤和生活便利度的人。

## 2. 功能清单

### 2.1 双地址搜索
- 输入框 A：意向居住地地址
- 输入框 B：上班地址
- 支持全国范围地址自动补全（高德地图输入提示）
- 确定地址后，地图自动定位并标记

### 2.2 生活圈分析
- 以地址 A 为中心，绘制半径 3km 的半透明蓝色圆形覆盖区
- 在圆内搜索 5 类 POI（勾选开关控制显隐）：
  - 便利店
  - 地铁站
  - 公交站
  - 公园
  - 医院
- 各类 POI 以不同颜色/图标在地图上标记

### 2.3 数据统计面板
- 各类 POI 数量以卡片形式展示
- 可展开查看每类 POI 的详细列表
- 列表项显示：名称 + 距离中心点的直线距离

### 2.4 POI 可达性评价 (P1-3)
- 每类 POI 显示：数量 + 最近距离 + 评价（较方便/一般/偏弱/暂无）
- 评价规则基于最近距离和数量综合判断
- 无数据的类别仍显示，不隐藏

### 2.5 通勤分析
- 自动计算 A→B 的出行方案
- 公共交通：预计时间、步行距离、换乘次数
- 驾车：预计时间、路况信息
- 骑行/步行方案
- 结果在侧边栏展示

### 2.6 通勤推荐 (P1-4)
- 自动推荐最适合日常通勤的方式（优先公交 > 驾车 > 骑行 > 步行）
- 展示推荐理由和注意事项（路况风险、通勤压力等）
- 推荐方式默认展开，其他方式折叠

### 2.7 居住评分与结论 (P1-1, P1-2)
- 0-100 分评分模型，涵盖通勤(35)/交通(25)/生活(15)/医疗(15)/休闲(10)
- 自动生成优势和短板分析
- 结论摘要卡：总分 + 等级 + 分数条 + 引导文案
- 输入地址 A 后即可获取 POI 维度评分，输入 B 后获得完整通勤评估

### 2.8 收藏管理（需登录）
- 用户可收藏地址 A，自定义备注名称
- 收藏列表可随时切换查看
- 收藏数据持久化存储
- 收藏时显示当前评分快照预览 (P1-6)
- 删除前确认提示

### 2.9 候选清单 (P2-1, P2-2)
- 将当前居住地分析保存为候选（localStorage）
- 候选状态：考虑中/已看过/重点考虑/暂不考虑
- 加入候选时捕捉评分、通勤推荐、POI 可达性快照
- 点击候选可回填地址 A/B，系统重新计算实时数据
- 候选清单保存在当前浏览器，尚未同步到账户

### 2.10 多候选对比 (P2-3, P2-4)
- 从候选清单生成横向对比视图
- 6 维对比（综合/通勤/交通/生活/医疗/休闲），含维度优胜标注
- 桌面端表格 + 移动端卡片列表
- 候选少于 2 个时提示添加更多候选

### 2.11 偏好模式 (P2-5)
- 5 种场景偏好：均衡/通勤优先/生活便利优先/交通优先/医疗优先
- 不同偏好模式下候选排序自动更新
- 偏好模式保存到 localStorage

### 2.12 复制对比报告 (P2-6)
- 一键复制候选对比结果为纯文本报告
- 报告含：候选明细、维度优胜、风险提醒
- 不做 PDF，不引入依赖

## 3. 页面布局

### 桌面端
```
┌──────────────┬─────────────────────┐
│  侧边栏      │                     │
│  (~400px)   │     高德地图         │
│  滚动区域    │     全屏铺满         │
└──────────────┴─────────────────────┘
```

### 移动端（<768px）
```
┌─────────────────────┐
│      地图区域        │
│     (~50vh)         │
├─────────────────────┤
│  底部抽屉式面板      │
│  可上下拖动切换高度  │
└─────────────────────┘
```

## 4. 交互流程

```
打开页面 → 输入地址 A → 地图定位 + 绘制 3km 圆
       → POI 自动搜索 → POI 可达性评价更新
       → 居住评分（POI 维度）
       → 输入地址 B（可选）
       → 通勤路线自动计算
       → 通勤推荐 + 完整居住评分
       → 结论卡展示总分/等级/优劣势
       → [登录后] 点击收藏 → 评分快照预览 → 保存当前地址 A
```

## 5. 非功能需求

- 首屏加载 < 3 秒
- 地图交互流畅（标记点 < 100 时无明显卡顿）
- 支持 Chrome/Firefox/Edge/Safari 主流浏览器
- 移动端触摸交互友好
- API Key 仅在前端暴露 JS API Key，Web 服务 Key 走服务端代理
